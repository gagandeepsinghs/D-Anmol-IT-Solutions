# Course module images

Each course has its own folder below. Add a photo for a module using its order in the course pathway:

- `module-01.jpg` - first module
- `module-02.jpg` - second module
- Continue numbering for later modules.

Supported formats are `.jpg`, `.jpeg`, `.png`, and `.webp`. Custom photos override the built-in module image for that course only. Leave a module image out to keep its built-in default.
